Email delivery mode

If institutional SMTP is configured (env vars FEEDBACK_SMTP_HOST etc.), real email is sent. Otherwise a safe dev mode writes each message as an .eml file into app/outbox/ so you can test the whole flow offline — open a file, copy the link, submit as a student.
